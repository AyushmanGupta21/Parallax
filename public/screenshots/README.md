# Screenshots

This directory contains UI screenshots for the Parallax README and submission documentation.

## Required Screenshots

Add the following files to this directory:

| Filename | Description |
|---|---|
| `wallet-connected.png` | Navbar showing connected wallet address and Testnet badge |
| `balance.png` | Dashboard balance card and recent transaction history |
| `transaction-success.png` | Transfer page after a successful XLM transaction |
| `dashboard.png` | Full dashboard view — API key, price feed table, registration status |
| `mobile-view.png` | Mobile responsive layout (any page) |

Screenshots are embedded in the root `README.md` and referenced from `./public/screenshots/<filename>`.
